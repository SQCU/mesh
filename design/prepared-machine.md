# Prepared machine

## Implementation basis

Use this synthesis when changing the resident path. Requirements determine the algorithm; existing code and prior passing builds do not establish that the algorithm is satisfied.

For the caller's FFN partition, `G_i = activation(X W_gate,i, X W_up,i)`, `P_i = G_i W_down,i`, and `Y = sum_i P_i`. Column-local activation needs no communication; completed output sections are pushed directly to each supplied consumer. Each reduction input contributes once to its designated output section. Cheap replicated operations introduce no extra collective. The transport only delivers these operands; numerical dependencies and arithmetic remain in the supplied function.

| Primary reference | Mechanism used here | Implementation consequence |
| --- | --- | --- |
| [Pallas BlockSpec and kernel arguments](https://docs.jax.dev/en/latest/pallas/quickstart.html) | A kernel receives references to selected input/output blocks. | Addresses, ranges and destination values are operands. A new layer binding does not introduce a callback type or a new numerical implementation. |
| [Megatron, section 3](https://arxiv.org/html/1909.08053v4) | Column-parallel first projection and row-parallel second projection eliminate an intermediate communication boundary; cheap operations may be replicated. | Preserve the algebra above. The caller chooses the partition; Mesh adds neither a numerical executor nor a placement cost model. The paper's bulk collective scheduling is not the project's streaming transport. |
| [Persistent kernels](https://triton-lang.org/main/getting-started/tutorials/gluon/persistence.html) | One program processes multiple work units; assignment can be static. | Persistence is a lifetime property. It does not require expansion of numerical bodies for every layer. This NVIDIA example supplies no Metal cross-threadgroup progress guarantee. |
| [Apple Metal compilation and dynamic libraries](https://developer.apple.com/videos/play/wwdc2020/10615/) | AIR compilation and GPU pipeline compilation are distinct; compiled device functions can be shared and linked at pipeline creation. | Numerical variants depend on arithmetic types/shapes, not buffer identity. Keep prepared control small. Use native separate compilation if ordinary function boundaries still permit pathological expansion; do not add an opcode interpreter or runtime linker. |
| [Apple shader-size guidance](https://developer.apple.com/videos/play/wwdc2022/10102/) | Inlining/unrolling can increase compilation cost, register pressure and instruction-cache misses. | No forced expansion of large stages. Small fixed fan-out stores may be unrolled. Neither a `noinline` annotation nor AIR compilation proves the resulting GPU code's cost. |
| [JACCL native transport](https://github.com/ml-explore/mlx/blob/main/mlx/distributed/jaccl/lib/jaccl/rdma.h) | Native SEND/RECV posting and completion polling. | Requests, endpoints and consumer placement are prepared before execution. Keep native polling; add no receipt-time binding discovery, payload copies or numerical work to transport threads. |

Preparation resolves scopes, registered backing, aliases, native requests and function bindings. Execution supplies those operands to resident functions. Publication must stay at the numerical visibility point; changing an ABI must not move it behind an added barrier, return-to-host or descriptor walk. Input delivery can reveal availability, but cannot decide the value's destination or invent its identity.

Review the generated full step as well as the generator: specialization keys must exclude layer addresses and callable identity; reduction must still accept any arriving term; multi-row publication must still cover its declared extent; shutdown must finish accepted finite work. Check that native by-value operands do not become chained metadata lookups or unaccounted spills on the crossing path. Required numerical loads, native completion polling and arithmetic dependencies are distinct from an invented admission protocol.

Current application: replace the FFN/vocabulary `Publish` and finish `Reduce` parameters with destination/value and input-address operands; remove their per-layer closure generation. The operand change is pending full pipeline compilation. The prior `423cba1` build and AIR check passed, but its full pipeline exceeded a 120-second compiler-only bound. The exact backend stall is unresolved; no runtime speedup or load-depth improvement is established by that result.
