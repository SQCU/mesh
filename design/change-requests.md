# Change requests

A change request states each requirement in this form:

> Producer produces result through algorithm, data structure or method (source). Consumer uses that result for its named operation.

Each clause identifies its source by author, title and section, a reference implementation and symbol, or an
operator turn. The [operator's format instruction](documentary-review-2026-11-13.md#positive-mechanism-form-2026-11-14)
governs this form. The declarative sentences in requests specify assigned behavior; implementation evidence lives
in dated records with source revisions and observations.

Algorithm and data-structure names use the words of the cited sources, with ordinary grammatical variation.
The operator's naming instructions are recorded in the history of this file at `cdd44406`; they specify vocabulary.
An assigned renaming proceeds through the operator's annotation-and-renaming sequence recorded there.

The [composition request](compilation-composition-change-request.md#reusable-form) supplies the form for composing
several requests through their producer/result/consumer relationships. A specification's open representation
choices are recorded as the implementer's choices with their reasons, following AOT's operator instruction T178
and its clarification recorded at `cdd44406`.

The [index](change-requests-index.md) separates active requests from completed history. The
[dated work account](compiler-uncovered-work-2026-11-14.md#recorded-state-2026-11-14) records implementation progress
and remaining complaints. Completed requests remain available as documentary history.
