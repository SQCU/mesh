# Exclusive resource order and page reuse, 19 November 2026

**A.** R5 selected a whole-program instruction order and the successive occupants of each exclusive resource. Each function sorted its instructions again. The storage planner computed a transitive closure of the original function dependencies, so its lifetime comparison omitted order that R5 had established between independent arithmetic operations. The first call supplied the function schedule even when another call to the same function admitted a different order. [R5](../../design/plan-to-bridge-change-request.md) · [A10](../../design/aot-compilation-change-request.md)

**B.** R5 now returns each call’s restriction of its selected permutation and a reachability table for completed accesses. The graph module combines the original dependencies with the forward edges of exclusive compute resources, then computes strict ancestor sets in the selected order. Link service can finish before bytes arrive. Its resource edges therefore count toward service capacity and its data edges govern arrival. The lifetime query reads the producer’s ancestor sets and grants precedence between two buffers when every access to the first precedes every access to the second in every occurrence of the function. Source values and Metal workspaces use that same query. The saved compilation carries the call orders and reachability bits. [Producer](../../../../compiler-emit/compiler_emit/completion.py) · [Graph interface](../../rdma/mesh-graph.h) · [Lifetime query](../../../../compiler-emit/compiler_emit/storage.py)

A public FX program computed two independent chains of elementwise operations on 1,024 floats and added the results. In its single-call form, the compiler placed the sine and sigmoid buffers on page 1 with one exclusive compute resource. With two independently runnable resources it placed them on pages 1 and 4. In its two-call form, both calls selected sine before sigmoid on the shared resource, while the two calls disagreed on sine before the absolute-value buffer. Their common lifetime table preserved that distinction. The queue backend and fresh and reopened Metal programs each returned the eager result on three inputs for all four combinations. The page numbers describe these runs. The allocator can choose any frame allowed by the retained precedence relation.
