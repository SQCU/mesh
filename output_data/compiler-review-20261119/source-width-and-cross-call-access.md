# Source call width and cross-call dependence, 19 November 2026

## A. What the inputs used to say

The outer compilation took a caller's bound for each callee before it split the FX graph. Four therefore entered as the bound for both independent calls and a chain of calls reading each other's results. At the command boundary, the dependency solver had already identified the writes, reads and overlapping byte ranges. The completion planner reduced that relation to instruction-number pairs. The native consumer allocated a new array of the same pairs. [Earlier review](change-request-coverage.md)

## B. What the two producers return

For an outer FX program, source analysis computes the transitive closure of its call dependencies and uses the graph library's chain decomposition on occurrences of each callee. The width counts the maximum number of mutually independent occurrences. A caller can supply a tighter limit. The compiler uses the resulting bound before it shards or fuses the calls. A caller submitting a standalone prepared function supplies its own bound on outstanding invocations. [A10](../../design/aot-compilation-change-request.md#a10-call-analysis-produces-ordering-and-concurrency-bounds) · [Source analysis](../../../../compiler-emit/compiler_emit/source.py) · [Standalone operand](../../../../compiler-emit/docs/source-analysis.md)

For several calls, the completion planner gives the original access views and supplied effect endpoints to the native dependency solver. It keeps the solver's relation plus the indices of the edges that order those calls. Metal reads the selected edges through those indices. Each edge identifies its contributing conflicts, including the index of an explicitly supplied effect or the pair of strided accesses. Native compilation stores the index table and relation in the current serialized program. Loading that program restores both. Two independent calls of the same sigmoid had width two. Feeding the first result to the second gave width one. A split seven-call graph had callee widths three and two. Seven fresh rank images and their reopened versions agreed on selected cross-call edge indices, serialized access relations and posting order. In the two-page case the two dependence edges identified the writes at offsets 0 and 16,384. Two calls using the same Torch random generator retained supplied effect number zero on instruction edge 1→5 in both the live and reopened compilation. With opposite tail costs, Metal issued opposite first calls, and the fresh and reopened images returned the eager Torch results. These runs exercised the compiler on this Mac. The separate collective run measured transport on the physical bridges.
