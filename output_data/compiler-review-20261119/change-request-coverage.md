## What the scheduler now does

For each occurrence of a function, the compiler puts its numerical instructions and its selected transfer hops in the same completion-time problem. It adds cross-call reads, writes, effects and rank-local submission constraints. Instructions on the same device resource or the same directed link compete for capacity. The R5 linear program supplies priorities to the heap-based topological sort. Storage reads the resulting resource order and iteration distances. The Torch and Metal emitters read each occurrence's instruction positions. A debugger counted two body expansions, one whole-program completion solve and two projections for a two-body graph. [R5](../../design/plan-to-bridge-change-request.md#r5-one-solve-orders-computation-and-transfers) · [Producer](../../../../compiler-emit/compiler_emit/completion.py) · [Consumers and debugger record](../../../../compiler-emit/artifacts/joint-sharding-20261119/whole-program-completion.md)

Two examples discriminate this change from a compiler that merely returns the right tensors. In one, the first call sends two 16-KiB ranges. The sine reads the first and the cosine reads the second. In this review the existing client again produced exactly the two edges `14 → 18` and `15 → 20`. In another, two independent branches compete for the same device. Interchanging their tail costs reversed the heads' modeled completion times from `(1, 2)` to `(2, 1)`. The recorded Metal commands changed from A–B–A to B–A–B. The repeated sharded program also preserved returned views and the caller's mutated weight. Its direct and relayed compilations contained 227 and 262 vertices respectively. These are instruction counts. The evaluator used local page copies for transfer. ## Three places where the solver already knows more than its caller or consumer uses

1. **A10 assigns call analysis the concurrency bound.** For each callee, the bound is the largest number of its calls that the dependence order leaves mutually unordered. Mesh already computes it by chain decomposition of the closure. In the revised entry, `SourceCallOrder` takes a limit from the caller or function operand. Later code correctly projects that number onto source occurrences and rank-local submissions. In this review, `f(x), f(x)` had width two and `a=f(x), f(a)` had width one. Both source operands still carried the supplied four. Data dependencies still ordered the dependent pair. The missing connection is the original callee's width feeding the bound operand before sharding. A deliberately tighter admission limit can remain a distinct input. [A10 and its specified width](../../design/compilation-coordination.md) · [Existing width calculation](../../compiler/mesh_compiler/schedule.py#L703) · [Revised source operand](../../../../compiler-emit/compiler_emit/source.py#L28)
2. **Composition §6 assigns each dependence its cause.** For cross-call memory accesses, `dependences_views` already returns a relation with the conflicting access records. `intercall_dependencies` selects the cross-call edges, adds effect edges and returns sorted instruction pairs. The completion result and its native view preserve those pairs. They omit the reference from each such edge to the access records or effect that produced it. Order survives. A consumer asking which write to which tensor range justified a particular wait has lost the direct answer. Pass the relation and its correspondence through to the signature and lowering. [Composition §6](../../design/compilation-composition-change-request.md#6-carry-compilation-results-through-their-consumers) · [Access relation](../../rdma/mesh_graph.py#L1437) · [Projection](../../../../compiler-emit/compiler_emit/completion.py#L121) · [Native result](../../../../native-execution/native_execution/planning.py#L238)
3. **Disjoint pages D.3.5 assigns page reuse to the previous receive and its final readers.** For a reused receive range across iterations, `ExtentPlan` substitutes one credit for the previous invocation. The Metal caller publishes that credit after `MetalProgramEnd`. An unrelated late operation can therefore hold a page whose final reader has already finished. This extent path also expands a fixed installation count and accepts one invocation per submission. The missing consumer is the bridge repost for that range, using the completion of its actual readers. The successful same-block partial-arrival example exercises a different edge. ## Serialization scope

The operator clarified on 19 November that the revisions in this work invalidate earlier archive formats. A9 covers writing the current executable, bindings and IR into caller-owned extents and reading those current-format results by view. An owner may retain an extent for another optimization round or free it after its final reader. Earlier formats impose no migration, replay or fixture obligation. The native loader currently accepts five outer format identifiers. That compatibility is extra implementation, and an old file opening or failing to open contributes nothing to the coverage above.
