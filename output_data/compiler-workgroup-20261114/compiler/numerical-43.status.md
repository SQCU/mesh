# numerical-43: matrix_exp in its computation dtype (SAME64), operations.py only, source HOLD, unstaged
> "_matrix_exponential rejects BF16 because SQUARING only F32/F64 … Use existing canonical Torch opmath computation dtype owner" (numerical-43.md)
- **Change:** `_matrix_exponential` now casts its input with `a.to(get_computation_dtype(a.dtype))` from `torch._prims_common` (bfloat16 and float16 to float32, complex32 to complex64, any other kind as given) and runs the same JAX scaling, Padé and squaring composition in that dtype. `where(over, nan, result).to(given)` is then the `dep_token` of `_functional_assert_async.msg`, so the cast and NaN result is written before the check.
- **Unchanged:** for f32/f64/c64/c128 both `.to` calls are the identity. The empty-input return, batches, `MATRIX_EXP_SQUARES` and the `max_squarings` NaN plus error path are also untouched.
- **Boundary:** JAX's `TypeError('A.dtype=… is not supported')` is now a NotImplementedError ("its scaling and squaring table is unfinished", item 6), with the rejection-filter comment.
  - The documented matrix_exp kinds compute in f32/f64/c64/c128. Fake admission of other floating kinds alone does not establish upstream matrix_exp support; the explicit unfinished-formulation error remains for a computation kind without a table.
- **Padé choice operand, source fact:** the choice is `norm = a.abs().sum(-2).amax(-1)`, over the batch domain in the computation dtype. It is compared with the static `SQUARING[real]` thresholds (f32 `conds` for degrees 3/5/7; f64 for 3/5/7/9/13).
  - Every degree's (u, v) is computed for every member. Branch j keeps the previous result where `norm < conds[j-1]`: a batched `torch.where`, with no scalar control.
- **Can `_Repeat` express one selected branch?** Yes, but only at record level: per member, with a one-element int32 condition, once-gated (as in `_dlahqr`'s DLANV2 gate and `_matrix_exp_squares`). The make_fx formulation cannot reach it without a fake-only operator like `MATRIX_EXP_SQUARES`, which would be a new schema and was not made in this unit.
- **Checks:** AST passes. pyflakes shows only the 2 warnings already at HEAD (`real` at 1077, `two` at 4689). Delta is operations.py +13/−3. No import, target, build, test or backup.
