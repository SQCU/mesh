# Spectral tolerance, rank and termination source review

Read-only review against source-lowering change request §6 and the already retained primary sources; no numerical invocation or new admission rule.

- `operations._pseudoinverse` (2198): default relative tolerance is the real input precision epsilon times max(m,n), or zero where an explicitly supplied absolute tolerance is positive. Tensor tolerances retain their supplied dtype and broadcast domain. Each matrix uses max(atol,rtol*max(abs(S))) and a strict greater-than cutoff; the Hermitian branch uses eigenvalue magnitude and signed reciprocals. Empty inputs return the correctly transposed empty shape. Existing actual rank-deficient indefinite pinv evidence is separate from this source review.
- `_least_squares_svd` (3433): explicit/default rcond is retained after the existing range scaling. GELSS uses max(rcond*S1,safemin), substituting precision epsilon for a negative rcond (Reference-LAPACK dgelss 385–386,509–521). GELSD uses the source DLALSD epsilon/2 fallback for rcond outside (0,1), and the N=1 nonzero test (dlalsd 235–276). Fixed-result projection changes no rank/solution formula. The ordinary tall batched native caller remains pending its matching build.
- `_polar` and `_bounded_polar` retain the QDWH coefficient schedule, remaining bounded Halley steps, iterate-change convergence result and final refinement. `_singular_qdwh` and the eigh split caller do not expose that flag; the retained JAX svd/eigh callers also discard it. There is no independent public QDWH nonconvergence error result to claim as verified. The supplied algorithm's finite inner bound does not prove convergence.
- Eigh subspace acceptance uses the retained off-block Frobenius residual at 10*unit-roundoff. Its existing Repeat continues while the residual improves but remains above tolerance; the outer remedy Repeat restarts from the source polar/Haar remedies until accepted. No invented finite retry limit was added. Actual termination/restart counts have not been measured; prior final condition zeros do not establish zero passes.
- Real and complex GEEV retain their source LAHQR iteration limit and positive INFO on exhaustion; the common result reaches the existing Check. Invalid-input negative INFO and same-Program recovery are observed in the retained domain client. Exhaustion itself has not been induced or observed, and no altered iteration bound was introduced for a test.

This review establishes the named producer/consumer source correspondences. It does not promote unmeasured precision, ANE execution, or nonconvergence behavior to completed runtime coverage. Current source and reference hashes are in spectral-contract-source.json.
