## Source construction and physical binding lifetime

`rdma/mesh_compile.py program` captures `_Export` once, but its `make` always calls `_retire` then `_built`. `_runner.execution` marks stale for ESTALE and ECANCELED. `_retire` releases all Programs/builders through `state[owned]`; `_built` redoes partition, `_lowering`/`_Builder`, metal_ir_lower, lifetimes, actors and call analysis. This loses unchanged numerical construction when only the routing/view/cancellation generation changed. Actual partition inputs include node count/self, page and fixed placement/target, plus program membership for deliveries. Serial/sequencer/boot are plan identity; the current `_bound` compares them, but they need not change numerical placement.

Existing final artifact restore is a separate legitimate boundary: metal_ir archive + native program load retain compiled objects and bind them through `_bound`; they do not re-run source numerical lowering. It does not solve pre-finalization reuse: `metal_ir_finalize` changes kernels through TransportMask/Wrap/Generate and clears body/transport handles. Resetting `finalized` or calling append/archive as a scratch clone would discard the actual stage contract.

Paired implementation is now assigned to SAME numerical session64ddaf6e: retain immutable lowered construction, canonical clone only emission-mutated kernel modules into an owned specialization, retain stable ValueID/dispatch and analysis results, and separate Python construction ownership from per-plan bindings. Executor's new whole-target consumer uses the same API. Plan-mutated values/marks require per-binding records; no guessed dictionary cache or repeated Transform/Lower/Artifact. Completed target sharing must follow actual emission operands. This connection remains OPEN until source+consumers are reviewed and built.

Additional header/caller sweep: remaining graph room/count APIs either output into an algorithmically bounded buffer or format existing retained records. No further solve-twice capacity path was found in the inspected mesh-graph/collective/Metal callers. This does not claim every codebase mechanism is covered.
